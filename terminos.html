Código de Conducta

Última actualización: 28 de febrero de 2026

Al acceder y utilizar Dev Path, aceptas cumplir con los siguientes términos y condiciones. Si no estás de acuerdo con alguna de estas reglas, no podrás participar en nuestras misiones.

1. Licencia de Uso

Otorgamos una licencia personal y limitada para acceder al material educativo. El contenido es para uso personal y no comercial.

2. Comportamiento en la Nave

Para mantener una comunidad sana, todos los usuarios se comprometen a:

  • Respetar a los compañeros y no utilizar lenguaje ofensivo.
  • No intentar vulnerar la seguridad del sitio ni realizar ataques técnicos.
  • No realizar trampas para ganar XP o monedas de forma artificial.

3. Propiedad Intelectual

Todo el software, diseño y arte (incluyendo elementos inspirados en Peppa Pig) son propiedad de Dev Path o se usan bajo licencias educativas.

Dev Path no garantiza que el servicio sea ininterrumpido. El aprendizaje depende del esfuerzo individual del estudiante.
