1. ¿Qué es una Base de Datos?

Una Base de Datos (BD) es como un archivero gigante y súper organizado. Si en tu juego quieres guardar el progreso de los jugadores para que no pierdan sus cosas al apagar la computadora, necesitas una BD.

2. Tablas, Filas y Columnas

En las bases de datos relacionales (las más famosas), la información se guarda igualito que en una hoja de Excel.

  • La Tabla: Es la hoja entera. Ej: La tabla "Usuarios".
  • Las Columnas: Son las características. Ej: Nombre, Edad, Puntos.
  • Las Filas: Es cada registro individual. Ej: "Peppa", "12", "5000".

3. Tu primera consulta SQL

El lenguaje SQL es la forma en la que "hablamos" con la base de datos para pedirle información. Literalmente le decimos "Selecciona esto de aquí".


-- Para ver TODOS los datos de la tabla usuarios:
SELECT * FROM Usuarios;

-- Para ver solo a los jugadores con más de 1000 puntos:
SELECT nombre, puntos 
FROM Usuarios 
WHERE puntos > 1000;

4. Llaves Primarias (Primary Key)

En una base de datos, no podemos confundir a los usuarios. ¿Qué pasa si hay dos personas llamadas "Peppa"? Para eso existen las Llaves Primarias.

Una Primary Key (PK) es como tu número de DNI o tu carnet de estudiante. Es un número único de identificación que nunca se repite. Así, si queremos buscar a alguien, lo buscamos por su ID y no por su nombre.
