1. El Editor de Código

Un programador podría escribir código en el Bloc de Notas, pero sería una tortura. Por eso usamos Editores de Código. El más famoso y el que seguro vas a usar es Visual Studio Code (VS Code).

Es genial porque te colorea las palabras para que no te pierdas, te autocompleta el texto y te avisa cuando te falta cerrar una etiqueta.

2. La Terminal (Sin miedo a la pantalla negra)

En las películas de hackers siempre se ve a alguien escribiendo rapidísimo en una pantalla negra. Eso es la terminal. No es más que una forma de decirle a tu computadora qué hacer usando texto en lugar de usar el mouse.


# Para crear una carpeta nueva desde la terminal:
mkdir mi-nuevo-proyecto

# Para entrar a esa carpeta:
cd mi-nuevo-proyecto

3. Git: La máquina del tiempo

Seguro alguna vez guardaste un trabajo escolar como "Proyecto_Final_V2_ahorasi_FINAL.docx". Eso es un desastre para organizar el código.

Git es un sistema que toma "fotos" de tu código a medida que avanzas. Si rompes algo, puedes decirle a Git: "Oye, devuélveme el código a cómo estaba ayer en la tarde". ¡Es magia pura!


# Iniciar la máquina del tiempo en tu carpeta
git init

# Tomar una "foto" de los cambios que hiciste
git commit -m "Agregué la tarjeta de usuario"

4. GitHub

No confundas Git con GitHub. Si Git es la cámara de fotos, GitHub es como el Instagram donde subes esas fotos. Es una plataforma en la nube donde guardas tu código para que no se pierda, y donde otros programadores pueden ver tu trabajo o ayudarte a mejorarlo.
