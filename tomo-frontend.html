1. ¿Qué es el Frontend?

El Frontend es, básicamente, todo lo que ves en tu pantalla y con lo que puedes interactuar cuando entras a una página web. Imagina que hacer una web es como construir una casa:

  • HTML: Son los ladrillos, las paredes y el techo. Da la estructura.
  • CSS: Es la pintura, los cuadros y la decoración. Hace que se vea bien.
  • JavaScript: Es la electricidad y el agua. Hace que las cosas funcionen y reaccionen si tocas un botón.

2. Etiquetas HTML básicas

Para armar el esqueleto de nuestra página usamos etiquetas. Casi todas funcionan igual: las abres, pones algo adentro y las cierras con una barra diagonal /.

Aquí tienes las que vas a usar el 90% del tiempo:


<!-- Esto es un título grande -->
<h1>Bienvenido a mi web</h1>

<!-- Esto es un párrafo normal -->
<p>Aquí puedo escribir texto largo.</p>

<!-- Esto es un enlace para ir a otra página -->
<a href="https://google.com">Ir a Google</a>

<!-- Esto es una caja vacía para agrupar cosas -->
<div>
    <p>Este texto está dentro de una caja.</p>
</div>

3. Introducción a CSS

Ahora que tenemos el esqueleto, vamos a ponerlo guapo. En CSS seleccionamos una etiqueta HTML y le aplicamos "reglas" de diseño.

Por ejemplo, si queremos que todos los botones de nuestra página sean azules y tengan letras blancas, haríamos esto:


button {
    background-color: blue;
    color: white;
    padding: 10px 20px;
    border-radius: 5px; /* Esto redondea las esquinas */
}

Para no afectar a todos los botones por igual, solemos usar Clases. En el HTML le ponemos class="boton-magico" y luego en el CSS lo llamamos usando un punto antes del nombre: .boton-magico { ... }.

4. Flexbox y Grid (La magia de acomodar cosas)

Antes, centrar cosas en una web era un dolor de cabeza. Hoy tenemos dos superpoderes para organizar nuestra página sin sufrir:

Flexbox: Imagina que tienes una fila de libros. Flexbox te ayuda a acomodarlos fácilmente: todos a la derecha, todos a la izquierda, o con el mismo espacio entre ellos. Es ideal para organizar elementos en una sola línea (horizontal o vertical).


/* Así centramos todo perfectamente al medio */
.caja-flex {
    display: flex;
    justify-content: center; /* Centra en horizontal */
    align-items: center;     /* Centra en vertical */
}

CSS Grid: Imagina un tablero de ajedrez o de hundir la flota. Grid te permite dividir tu pantalla en columnas y filas, y luego decirle a cada elemento en qué cuadrito debe ir. Es perfecto para hacer la estructura general de la página (como acomodar el header, el menú lateral y el contenido principal).


/* Esto crea 3 columnas del mismo tamaño */
.cuadricula {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px; /* Espacio entre las tarjetas */
}

Y listo, con estas bases ya estás preparado para empezar a maquetar tus primeras aventuras en el código.
