1. ¿Qué es un Algoritmo?

Suena a palabra de científico, pero un algoritmo no es más que una receta de cocina. Es una serie de pasos ordenados para resolver un problema.

Si quieres hacer un huevo frito, el algoritmo sería:

  • 1. Poner el sartén al fuego.
  • 2. Echar un poquito de aceite.
  • 3. Romper el huevo y echarlo al sartén.
  • 4. Esperar a que se cocine y servir.

En programación, hacemos exactamente lo mismo, pero en lugar de huevos, procesamos datos.

2. Variables y Cajas

Imagina que tu computadora es una bodega gigante y una variable es una caja de cartón donde puedes guardar cosas. A cada caja le pones una etiqueta con un marcador para saber qué tiene adentro.


// Guardamos datos en nuestras "cajas"
nombre_jugador = "Peppa"
vidas = 3
puntuacion = 0

Lo genial de las variables es que, como su nombre lo indica, pueden "variar". Si pierdes una vida, simplemente actualizamos la caja: vidas = 2.

3. Condicionales (If/Else)

Los condicionales son como los guardias de seguridad del código. Toman decisiones basadas en una regla. "SI pasa esto, haz esto; SI NO, haz otra cosa".


si (vidas == 0) {
    mostrar_mensaje("¡Game Over!")
} sino {
    mostrar_mensaje("¡Sigue jugando, aún tienes vidas!")
}

4. Ciclos y Acumuladores

Las computadoras son increíbles haciendo tareas repetitivas sin aburrirse. Para eso usamos los ciclos (como FOR o WHILE). Además, cuando queremos contar cosas dentro de un ciclo, usamos un acumulador o contador.

Mira cómo funciona la lógica para contar del 1 al 10 e ir sumando puntos:


puntos_totales = 0  // Este es nuestro acumulador

para cada nivel desde el 1 hasta el 10:
    jugar_nivel()
    puntos_totales = puntos_totales + 100 // Acumulamos los puntos
    
mostrar_mensaje("Terminaste. Puntos: " + puntos_totales)

Dominar la lógica de los ciclos es la clave para hacer desde un cajero automático hasta un juego de la vida. ¡Es puro superpoder lógico!
